# Política de Segurança

A equipe do **Kore Framework** e a **Kodey Sistemas** levam a segurança do software a sério.

## Versões Suportadas

| Versão | Suportada          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reportando uma Vulnerabilidade

Se você descobrir uma vulnerabilidade de segurança no Kore Framework, **não abra uma Issue pública**. Em vez disso, siga o procedimento de divulgação responsável:

1. Envie um e-mail detalhado para **contato@kodey.com.br** com o assunto [Vulnerabilidade de Segurança - Kore Framework].
2. Inclua o máximo de detalhes possível: passos para reproduzir, prova de conceito (PoC), impacto potencial e sugestão de correção (se houver).
3. Nossa equipe responderá em até 48 horas úteis para confirmar a vulnerabilidade e trabalhar em um patch de segurança.
4. Assim que a correção for publicada, daremos os devidos créditos a você nas notas de lançamento (se você assim desejar).
